How a row is scored

Each signal is a point score, not an order. RSI, MACD, Bollinger bands, the 9/21 EMA cross, and a volume spike add bull or bear points. Strong buy needs the high bar. Otherwise the name stays on hold. Win rate is a backtest of those same rules, and it is left blank when that backtest did not return a number.
